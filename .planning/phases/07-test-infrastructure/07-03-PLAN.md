       - Navigate: `await page.goto('/songs')` (per user decision: factories navigate to the created item)
       - Return `data`

       **`createSetlist(page: Page, userId: string, overrides?: Record<string, unknown>)`:**
       - Defaults: `user_id: userId`, `name: \`${faker.word.adjective()} ${faker.word.noun()} Set\``, `gig_date: faker.date.future().toISOString().split('T')[0]`, `venue: faker.location.city()`, `target_seconds: faker.number.int({ min: 1800, max: 7200 })`, `transition_seconds: faker.number.int({ min: 0, max: 30 })`
       - Insert via `adminClient.from('setlists').insert(setlist).select().single()`
       - Throw on error
       - Navigate: `await page.goto(\`/setlists/${data.id}\`)`
       - Return `data`

       **`createBand(page: Page, userId: string, overrides?: Record<string, unknown>)`:**
       - Defaults: `owner_id: userId`, `name: \`${faker.music.genre()} ${faker.animal.type()}s\``
       - Insert band via `adminClient.from('bands').insert(band).select().single()`
       - Throw on error
       - Insert owner as band member: `adminClient.from('band_members').insert({ band_id: data.id, user_id: userId, role: 'owner' })`
       - Navigate: `await page.goto(\`/bands/${data.id}\`)`
       - Return `data`

       All factory functions use the service role client (bypasses RLS). Simple function names per user decision (no factory objects/builders).

       - Create admin client with service role key
