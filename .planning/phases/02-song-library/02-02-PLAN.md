    1. Create `src/routes/(app)/songs/+page.server.ts`:
       - `load` function: get session via `locals.safeGetSession()`, query `supabase.from('songs').select('*').eq('user_id', session.user.id).order('title', { ascending: true })`, return `{ songs: songs ?? [] }`
       - `delete` named action: get song `id` from formData, call `supabase.from('songs').delete().eq('id', id)`, on error return `fail(500, { error: 'Failed to delete song' })`, on success return `{ deleted: true }`

    2. Create `src/lib/actions/longpress.ts`:
       - Svelte action that dispatches a `longpress` CustomEvent after 500ms touch hold
       - Tracks `touchstart` position, cancels on `touchmove` > 10px threshold (prevents triggering during scroll)
       - Cleans up listeners in `destroy()`
       - Event detail includes `{ x, y }` coordinates for context menu positioning

    3. Create `src/lib/components/ui/ContextMenu.svelte`:
       - Props: `items` (array of `{ label, action }`), `x`, `y`, `visible`, `onclose` callback
       - Fixed position menu with boundary checking (adjust x/y if menu would go off-screen)
       - Closes on outside click via `svelte:window` onclick
       - Styled: rounded-lg, border, shadow-lg, stone colors, dark mode support
       - Each item is a full-width button with hover state
       - Stop propagation on menu click to prevent immediate close

    4. Create `src/lib/components/ui/ConfirmDialog.svelte`:
       - Uses native `<dialog>` element with `showModal()`
       - Exports a `confirm(title: string, message: string): Promise<boolean>` function
       - Promise-based: resolves true on confirm, false on cancel
       - Styled: rounded-xl, backdrop blur, Cancel (text button) + Delete (red button)
       - Dark mode support

    5. Create `src/lib/components/songs/SongSearch.svelte`:
       - Props: `searchQuery` (bindable), `durationFilter` (bindable), `onToggle` callback
       - Collapsible: starts hidden, expands when search icon is tapped
       - Search input: text field with placeholder "Search songs...", binds to searchQuery
       - Duration filter: row of pill/chip toggle buttons below search input -- "All", "< 3 min", "3-5 min", "> 5 min"
       - Values: `'all' | 'under3' | '3to5' | 'over5'`
       - Clear button (X icon) to reset search and filters
