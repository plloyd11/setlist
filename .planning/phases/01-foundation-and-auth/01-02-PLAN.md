  <name>Task 1: Set up theme system and FOUC prevention</name>
  <files>
    src/app.html
    src/lib/stores/theme.ts
    src/lib/components/layout/ThemeToggle.svelte
  </files>
  <action>
    1. Update `src/app.html` — add inline theme script in `<head>` BEFORE `%sveltekit.head%` to prevent FOUC:
       ```html
       <script>
         (function() {
           const theme = localStorage.getItem('theme');
           if (theme === 'dark' || (!theme && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
             document.documentElement.classList.add('dark');
           }
         })();
       </script>
       ```
       Also add Google Fonts link for Righteous (headings) and Nunito (body):
       ```html
       <link rel="preconnect" href="https://fonts.googleapis.com">
       <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
       <link href="https://fonts.googleapis.com/css2?family=Nunito:wght@400;500;600;700&family=Righteous&display=swap" rel="stylesheet">
       ```
       Set the body class to use Nunito as default body font: `font-family: 'Nunito', sans-serif;` (can be done via Tailwind `@theme` in layout.css instead).

    2. Create `src/lib/stores/theme.ts` — simple theme state:
       - Export a function `getTheme()` that reads from `document.documentElement.classList`
       - Export a function `toggleTheme()` that toggles `dark` class on `document.documentElement` and persists to localStorage
       - Keep it simple — no stores needed, just functions that manipulate the DOM directly (the ThemeToggle component handles its own reactivity with `$state`)

    3. Create `src/lib/components/layout/ThemeToggle.svelte`:
       - Use `$state` for `isDark` — initialize by reading `document.documentElement.classList.contains('dark')` in `onMount`
       - `toggle()` function: flip `isDark`, toggle `dark` class on `document.documentElement`, persist to localStorage
       - Button with `aria-label="Toggle dark mode"`
       - Show sun icon when dark (click to go light), moon icon when light (click to go dark)
       - Use simple SVG icons inline (sun and moon) — no icon library needed
       - Style: subtle button with `text-stone-500 hover:text-amber-500 dark:text-stone-400 dark:hover:text-amber-500`

    4. Update `src/routes/layout.css` to configure fonts via Tailwind v4 `@theme`:
       ```css
       @theme {
         --font-sans: 'Nunito', sans-serif;
         --font-display: 'Righteous', sans-serif;
       }
       ```
       This makes `font-sans` (default body) use Nunito and `font-display` available for headings.
