  <files>supabase/migrations/20260218100000_create_setlist_tables.sql</files>
  <action>
Create a single migration file with:

**profiles table** (user-level settings including logo):
- `id` uuid PK references auth.users(id) on delete cascade
- `display_name` text nullable
- `logo_url` text nullable
- `created_at` timestamptz default now() not null
- `updated_at` timestamptz default now() not null

**setlists table**:
- `id` uuid default gen_random_uuid() PK
- `user_id` uuid references auth.users(id) on delete cascade not null
- `name` text not null
- `gig_date` date nullable
- `venue` text nullable
- `target_seconds` integer with check (is null or > 0)
- `transition_seconds` integer not null default 0 check (>= 0)
- `share_token` uuid unique nullable (null = not shared; populated = shared)
- `created_at` timestamptz default now() not null
- `updated_at` timestamptz default now() not null

**setlist_songs junction table**:
- `id` uuid default gen_random_uuid() PK
- `setlist_id` uuid references setlists(id) on delete cascade not null
- `song_id` uuid references songs(id) on delete cascade not null
- `position` integer not null check (>= 0)
- `created_at` timestamptz default now() not null
- unique(setlist_id, position)

**Indexes:**
- setlists(user_id)
- setlists(share_token) WHERE share_token IS NOT NULL (partial index)
- setlist_songs(setlist_id)
- setlist_songs(setlist_id, position)

**RLS policies:**
- profiles: owner full CRUD (`for all to authenticated using (auth.uid() = id)`), anon SELECT (for shared view logo/name)
- setlists: owner SELECT/INSERT/UPDATE/DELETE to authenticated (using auth.uid() = user_id), anon SELECT where share_token IS NOT NULL
- setlist_songs: owner all via subquery (setlist_id in select id from setlists where user_id = auth.uid()), anon SELECT via subquery (setlist_id in select id from setlists where share_token is not null)

**Storage bucket:**
- Insert into storage.buckets to create a 'logos' public bucket
- Add storage policy: authenticated users can upload to their own folder (`logos/{user_id}/*`)
- Add storage policy: anyone can read from logos bucket (public)

Follow the exact RLS pattern from the existing songs migration (using `(select auth.uid())` subquery form for performance).
