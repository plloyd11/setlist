**+page.server.ts** — Create `src/routes/share/[token]/+page.server.ts`:
- This route is OUTSIDE the (app) group — no auth layout, no sidebar/nav
- Load function takes `params.token`
- Query: `supabase.from('setlists').select('id, name, gig_date, venue, user_id').eq('share_token', params.token).single()`
- If not found (no setlist or sharing disabled), throw error(404, 'Setlist not found')
- Query setlist_songs with ONLY song titles (no durations): `supabase.from('setlist_songs').select('position, songs(title)').eq('setlist_id', setlist.id).order('position')`
  - Note: setlist.id is available server-side from the first query; it's not exposed to the client
- Query profile for logo and display name: `supabase.from('profiles').select('display_name, logo_url').eq('id', setlist.user_id).maybeSingle()`
- Return `{ setlist: { name, gig_date, venue }, songs, profile }`
  - IMPORTANT: Do NOT return setlist.id or user_id to the client — only name, gig_date, venue

**+page.svelte** — Create `src/routes/share/[token]/+page.svelte`:
- Clean performance view — NO app chrome (no sidebar, no bottom nav, no header)
- Layout: centered, max-w-2xl, mx-auto, p-8
- Header section (centered text):
  - Logo image if profile?.logo_url (max-h-24, w-auto, mx-auto, mb-4)
  - Display name / band name if available (text-lg, text-stone-600)
  - Setlist name (font-display text-3xl)
  - Date and venue line if available (text-stone-500, "Venue — Date" format, format date nicely)
- Song list: ordered list (`<ol>`) with numbered entries
  - Each item: number + song title only. NO duration, NO notes.
  - Styling: border-b, py-2, text-lg, number in stone-400
- Footer: subtle "Powered by Setlist" or similar (text-xs, text-stone-400, mt-12, text-center). Optional.
