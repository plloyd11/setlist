**1. src/routes/(app)/bands/[id]/members/+page.server.ts:**

**Load function:**
- Get session. If no session, error 401.
- Load band members with profile info: `supabase.from('band_members').select('id, user_id, role, joined_at, profiles(display_name, logo_url)').eq('band_id', params.id).order('joined_at')`. Note: this requires the `profiles` table to be joinable -- the `user_id` FK to auth.users should work. If profiles aren't directly joinable, load members then fetch profiles separately by user IDs.
- Alternatively, since profiles.id = auth.users.id, and band_members.user_id = auth.users.id, join via `user_id`. Try: `.select('*, profiles!band_members_user_id_fkey(display_name, logo_url)')` or load profiles separately.
- Check if current user is owner (from parent layout data or re-query).
- Return `{ members }`.

**Form actions:**

`createInvite` (owner only):
- Verify current user is band owner: query bands where id = params.id and owner_id = session.user.id. If not owner, fail(403).
- Insert into `band_invites`: `{ band_id: params.id, created_by: session.user.id }`. The token is auto-generated by default column.
- Select the token back: `.select('token').single()`.
- Construct invite URL: `${url.origin}/bands/invite/${invite.token}`.
- Return `{ inviteUrl }`.

`removeMember` (owner only):
- Parse `member_id` (the band_members row id) from form data.
- Verify current user is owner.
- Prevent owner from removing themselves (must transfer first).
- Delete from `band_members` where `id = member_id`.
- Return `{ removed: true }`.

`transferOwnership` (owner only):
- Parse `new_owner_id` (user_id of new owner) from form data.
- Verify current user is owner.
- Update `bands` set `owner_id = new_owner_id` where `id = params.id` and `owner_id = session.user.id`.
- Update `band_members` set `role = 'owner'` where `band_id = params.id` and `user_id = new_owner_id`.
- Update `band_members` set `role = 'member'` where `band_id = params.id` and `user_id = session.user.id`.
- Return `{ transferred: true }`.

`leaveBand` (members only, not owner):
- Verify current user is NOT the owner (owner must transfer first).
- Delete from `band_members` where `band_id = params.id` and `user_id = session.user.id`.
- Redirect to `/bands`.

**1. src/routes/(app)/bands/invite/[token]/+page.server.ts:**

**Load function:**
- Get session. If no session, redirect to /auth with a return URL parameter so user comes back after login.
- Query `band_invites` for the token: `.select('id, band_id, bands(name, logo_url)').eq('token', params.token).is('used_at', null).gt('expires_at', new Date().toISOString()).single()`.
- If no invite found: error 404 "Invite link is invalid or has expired."
- Check if user is already a member of this band: query `band_members` where `band_id = invite.band_id` and `user_id = session.user.id`.
- Return `{ invite: { bandName, bandLogoUrl, alreadyMember } }`.

**Form actions:**

`accept`:
- Get session. If no session, fail(401).
- Re-query invite (validate still valid -- someone could accept between load and action).
- If invalid: fail(404, { error: 'Invite expired or already used' }).
- Check already member: if so, redirect to `/bands/{invite.band_id}`.
- Insert into `band_members`: `{ band_id: invite.band_id, user_id: session.user.id, role: 'member' }`.
- Handle unique constraint (23505): already a member, just redirect.
- Mark invite as used: update `band_invites` set `used_by = session.user.id, used_at = new Date().toISOString()` where `id = invite.id`.
- Redirect (303) to `/bands/{invite.band_id}`.
