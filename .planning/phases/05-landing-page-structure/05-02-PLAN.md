    Create `src/routes/+page.svelte` with these sections. The page is ALWAYS dark — use dark palette colors directly (bg-surface-950, text-surface-100, etc.) — do NOT use `dark:` variant classes. This ensures the dramatic aesthetic regardless of system preference.

    **3. Hero section (~70-80vh)**
    - Bold, oversized headline using Cartridge font. Example copy: "Know your set. Own the stage." Use `text-4xl md:text-6xl lg:text-8xl font-black font-display` for dramatic sizing. The headline text should be surface-100 with a key phrase (like "Own the stage") in neon-300 for emphasis.
    - Subheadline below: feature-focused, explains what the app does. Example: "Build setlists, track timing to the second, and keep your band in sync — all in one place." Use `text-lg md:text-xl text-surface-400`.
    - CTA button: "Build Your First Setlist" linking to `/auth?redirect=/dashboard`. Styled with `bg-accent-400 hover:bg-accent-300 text-surface-950 font-display font-bold px-8 py-4 rounded-lg shadow-glow-accent transition-all`. Large and prominent.
    - Center-aligned, generous padding (px-6), `flex flex-col items-center justify-center text-center`.

    **4. Feature sections (3 alternating rows)**
    Full-width sections with max-w-6xl container. Each section is a flex row that alternates screenshot left/right on desktop, stacks on mobile.

    Feature 1 — **Setlist Timing** (image left, text right):
    - Headline: "Every second, accounted for" (or similar — Claude's discretion on exact copy)
    - Description: 1-2 sentences about building setlists with real-time running totals, target times, and over/under indicators.
    - Screenshot: `/images/screenshots/setlist-timing.png`

    Feature 2 — **Song Library** (image right, text left — use `md:flex-row-reverse`):
    - Headline: "Your songs, always ready"
    - Description: 1-2 sentences about managing your song library with durations, search, and quick entry.
    - Screenshot: `/images/screenshots/song-library.png`

    Feature 3 — **Band Collaboration** (image left, text right):
    - Headline: "Your whole band, one page"
    - Description: 1-2 sentences about shared workspaces, collaborative setlists, and keeping everyone in sync.
    - Screenshot: `/images/screenshots/band-collaboration.png`

    Layout pattern for each feature row:
    ```
    <div class="flex flex-col md:flex-row {alternate ? 'md:flex-row-reverse' : ''} items-center gap-8 md:gap-16 py-16 md:py-24">
      <div class="w-full md:w-1/2">
        <img src={screenshot} alt={alt} class="rounded-xl border border-surface-700 shadow-lg" />
      </div>
      <div class="w-full md:w-1/2">
        <h2 class="font-display text-2xl md:text-4xl font-bold text-surface-100">...</h2>
        <p class="mt-4 text-lg text-surface-400">...</p>
      </div>
    </div>
    ```

    Use subtle gradient-fade dividers between major sections:
    `<div class="mx-auto h-px w-full max-w-4xl bg-gradient-to-r from-transparent via-surface-700 to-transparent"></div>`

    Centered section with dramatic typographic statements (not fake testimonials). Use Cartridge font at large sizes. Example statements:
    - "Every second of your set, accounted for."
    - "One library. Unlimited setlists."
    - "Your band, in sync."

    Each statement on its own line, `font-display text-xl md:text-3xl font-semibold text-surface-200` with key words in `text-neon-300` for emphasis.

    Below the statements: secondary CTA button "Build Your First Setlist" (same style as hero CTA) linking to `/auth?redirect=/dashboard`.

    **6. Footer**
    Minimal footer with border-t border-surface-800. Contains:
    - Logo text "Setlist" (font-display text-accent-400)
    - Links: "Sign Up" and "Log In" (both to /auth), styled text-surface-400 hover:text-surface-200
    - Copyright: "© 2026 Setlist" in text-surface-600
    - Flex row on desktop, stacked on mobile. Max-width container.

    **Responsive behavior:**
    - Mobile (< 768px): Single column, hero ~60vh, stacked features, text-4xl headline
    - Tablet (768px+): Side-by-side features, hero ~70vh, text-6xl headline
    - Desktop (1024px+): Full dramatic layout, hero ~80vh, text-8xl headline
