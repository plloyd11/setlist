  <name>Task 1: Server load and form actions for setlist list page</name>
  <files>src/routes/(app)/setlists/+page.server.ts</files>
  <action>
Create `src/routes/(app)/setlists/+page.server.ts` with:

**load function:**
- Query setlists for the authenticated user, ordered by updated_at desc
- For each setlist, also fetch the count of songs and the sum of song durations using a joined query or separate query
- Use: `supabase.from('setlists').select('*, setlist_songs(count)').eq('user_id', session.user.id).order('updated_at', { ascending: false })`
- Also compute total duration per setlist. Two approaches: (a) separate query joining setlist_songs with songs, or (b) fetch setlist_songs with songs(duration_seconds) and compute client-side. Use approach (b) — fetch all setlist_songs with their song durations grouped by setlist_id, and return a map of setlist_id -> { song_count, total_seconds }
- Actually, simplest approach: use a Supabase query with embedded select to get setlist_songs count. For total duration, query setlist_songs joined with songs and aggregate. Use two queries:
  1. `supabase.from('setlists').select('*').eq('user_id', session.user.id).order('updated_at', { ascending: false })` for setlist data
  2. `supabase.from('setlist_songs').select('setlist_id, songs(duration_seconds)').in('setlist_id', setlistIds)` for song counts and durations
- Build a stats map: `Record<string, { songCount: number; totalSeconds: number }>` from the second query
- Return `{ setlists, stats }`

**create action:**
- Accept `name` from form data (required, trimmed, non-empty)
- Insert into setlists table with user_id, name, transition_seconds: 0
- On success, redirect (303) to `/setlists/${newSetlist.id}` (the builder page)
- On failure, return fail(400) with error message

**delete action:**
- Accept `id` from form data
- Delete from setlists where id matches AND user_id matches (RLS also protects this)
- Return `{ deleted: true }`

**duplicate action:**
- Accept `id` from form data
- Load the original setlist (name, gig_date, venue, target_seconds, transition_seconds)
- Insert a copy with name `${original.name} (Copy)`, no share_token
- Load original's setlist_songs (song_id, position) and insert copies for the new setlist
- Return `{ duplicated: true }`

Follow the form action pattern from `src/routes/(app)/songs/+page.server.ts` (safeGetSession, fail() for errors).
