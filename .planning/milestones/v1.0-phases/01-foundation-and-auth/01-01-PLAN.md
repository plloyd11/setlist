
    3. Create `.env` with the same placeholders (user will fill in real values).
       Add `.env` to `.gitignore` if not already there.

    4. Update `src/app.d.ts` — extend App namespace with Supabase types:
       - `App.Locals`: `supabase: SupabaseClient`, `safeGetSession(): Promise<{ session: Session | null; user: User | null }>`
       - `App.PageData`: `session: Session | null`, `user: User | null`
       - Import types from `@supabase/supabase-js`

    5. Create `src/hooks.server.ts` — follow the exact pattern from RESEARCH.md Pattern 1:
       - Create Supabase server client with `createServerClient` using cookie handlers
       - Implement `safeGetSession` on `event.locals` (getUser() first for JWT validation, then getSession())
       - Auth guard: if path does NOT start with `/auth`, check session — redirect 303 to `/auth` if no session
       - Filter serialized response headers for `content-range` and `x-supabase-api-version`
       - CRITICAL: Always spread `{ ...options, path: '/' }` in setAll cookie handler

    6. Create `src/routes/+layout.server.ts` — follow RESEARCH.md Pattern 2:
       - Export load function that calls `safeGetSession()` from locals
       - Return `{ session, user, cookies: cookies.getAll() }`

    7. Create `src/routes/+layout.ts` — follow RESEARCH.md Pattern 2:
       - Call `depends('supabase:auth')` for reactivity
       - Use `isBrowser()` to create either `createBrowserClient` or `createServerClient`
       - For server client, pass `data.cookies` in `getAll()`
       - Return `{ supabase, session, user: data.user }`

    8. Update `src/routes/+layout.svelte` — follow RESEARCH.md auth state listener pattern:
       - Use `let { data, children } = $props()`
       - In `onMount`, set up `supabase.auth.onAuthStateChange` listener
       - When `session.expires_at` changes, call `invalidate('supabase:auth')`
       - Return cleanup function to unsubscribe
       - Render `{@render children()}`
       - Keep existing layout.css import

    9. Create `src/routes/auth/callback/+server.ts` — follow RESEARCH.md Pattern 3:
       - Export GET handler
       - Extract `code` from URL search params
       - If code exists, call `supabase.auth.exchangeCodeForSession(code)`
       - Redirect 303 to `/` (dashboard)

    10. Update `src/routes/layout.css` — add dark mode custom variant:
        - Keep existing `@import 'tailwindcss'` and `@plugin '@tailwindcss/forms'`
        - Add `@custom-variant dark (&:where(.dark, .dark *));`
  </action>

    - `.env.example` exists with both PUBLIC_SUPABASE_URL and PUBLIC_SUPABASE_PUBLISHABLE_KEY
    - `hooks.server.ts` contains `safeGetSession` and `createServerClient`
    - `auth/callback/+server.ts` contains `exchangeCodeForSession`
  </verify>
