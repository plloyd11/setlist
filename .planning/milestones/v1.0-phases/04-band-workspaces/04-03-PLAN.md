<task type="auto">
  <name>Task 1: Create band songs server routes with share, add, and remove actions</name>
  <files>src/routes/(app)/bands/[id]/songs/+page.server.ts</files>
  <action>
**Server load function:**
- Get session via `safeGetSession()`. If no session, error 401.
- Load band songs via junction: `supabase.from('band_songs').select('id, song_id, added_by, songs(id, title, duration_seconds, notes, user_id)').eq('band_id', params.id).order('songs(title)')`.
- Load user's personal songs (for the "share from library" picker): `supabase.from('songs').select('id, title, duration_seconds').eq('user_id', session.user.id).order('title')`.
- Return `{ bandSongs, personalSongs }`.

**Form actions:**

`shareSong` -- Copy a personal song to band library:
- Parse `song_id` from form data.
- Insert into `band_songs`: `{ band_id: params.id, song_id, added_by: session.user.id }`.
- Handle unique constraint violation (23505) gracefully: return fail(409, { error: 'Song already in band library' }).
- On success return `{ shared: true }`.

`addNew` -- Create a new song directly for the band:
- Parse `title` (required), `duration` (required, use parseDuration from existing utils), `notes` (optional) from form data.
- Validate: title non-empty, duration parses to positive seconds.
- Insert into `songs` table: `{ title, duration_seconds, notes, user_id: session.user.id }` -- creator owns the song row.
- Then insert into `band_songs`: `{ band_id: params.id, song_id: newSong.id, added_by: session.user.id }`.
- Return `{ added: true }`.

`removeSong` -- Remove a song from band library (does NOT delete the song itself):
- Parse `band_song_id` from form data.
- Delete from `band_songs` where `id = band_song_id`.
- Return `{ removed: true }`.

`updateSong` -- Edit a band song inline:
- Parse `song_id`, `title`, `duration`, `notes` from form data.
- Update `songs` table: `.update({ title, duration_seconds, notes }).eq('id', song_id)`.
- The RLS policy for band-linked songs allows this UPDATE.
- Return `{ updated: true }`.

Import `parseDuration` and `formatDuration` from existing utils (check `src/lib/utils/` for the duration utility file).
