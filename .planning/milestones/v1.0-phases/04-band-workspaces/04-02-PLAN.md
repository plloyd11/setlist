**1. src/routes/(app)/bands/[id]/+layout.server.ts:**

Load function:
- Get session via `safeGetSession()`. If no session, error 401.
- Query `bands` table for `id = params.id` (RLS ensures only band members can access). `.single()` -- if null, error 404 "Band not found".
- Query `band_members` for the current user's role in this band: `.eq('band_id', params.id).eq('user_id', session.user.id).single()`.
- Return `{ band, isOwner: membership?.role === 'owner' }`.

This layout data is available to ALL child routes (songs, setlists, members, dashboard).

**2. src/lib/components/bands/BandNav.svelte:**

Sub-navigation tabs component. Props: `bandId: string`.

Tabs array:
- { href: `/bands/${bandId}`, label: 'Dashboard', exact: true }
- { href: `/bands/${bandId}/songs`, label: 'Songs' }
- { href: `/bands/${bandId}/setlists`, label: 'Setlists' }
- { href: `/bands/${bandId}/members`, label: 'Members' }

Use `$page.url.pathname` for active state detection. Active tab gets amber border-bottom and amber text (matching existing design language). Use the `isActive` helper pattern: exact match for Dashboard, startsWith for others.

Style: horizontal tab bar with `border-b border-stone-200 dark:border-stone-700`, amber accent for active tab.

Per locked decision: "Inside a band, sub-navigation shows band-specific tabs: Songs, Setlists, Members -- feels like a distinct workspace."

**4. src/routes/(app)/bands/[id]/+page.server.ts:**

Dashboard data loader:
- Get band_id from params and session from locals.
- Count band members: `band_members` count where `band_id = params.id`.
- Count band songs: `band_songs` count where `band_id = params.id`.
- Fetch recent setlists (last 5): `setlists` where `band_id = params.id`, order by `updated_at desc`, limit 5. Select name, gig_date, venue.
- Return `{ memberCount, songCount, recentSetlists }`.
