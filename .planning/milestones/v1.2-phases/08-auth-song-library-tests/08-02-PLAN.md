**Add song (SONG-01):**
- `should add a song with title and duration`: Navigate to `/songs/new`. Fill title (`page.getByLabel('Title').fill('Test Song Alpha')`), fill duration (`page.getByLabel('Duration').fill('3:45')`). Clean up: use admin client to delete the song by querying for it, or rely on worker teardown.

**Form validation (SONG-01 negative):**
- `should prevent submission when title is empty`: Navigate to `/songs/new`. Leave title empty, fill duration `3:45`. Click submit. Assert the form did NOT navigate away (still on `/songs/new`). The HTML5 `required` attribute on the title field prevents submission -- assert the title input has a validation message or the page URL hasn't changed.
- `should prevent submission with invalid duration`: Navigate to `/songs/new`. Fill title `Valid Title`, fill duration with invalid value like `abc`. Click submit. Assert the page stays on `/songs/new` (HTML5 pattern validation or server-side rejection).

**Edit song (SONG-02):**
- `should edit song title and duration via inline edit`: Use `createSong(page, testUser.id, { title: 'Before Edit', duration_seconds: 225 })` to set up. On `/songs`, click the song text `Before Edit` to enter edit mode. Fill `input[placeholder="Song title"]` with `After Edit`. Fill `input[placeholder="3:45"]` with `5:00`. Click save button (`page.getByLabel('Save')`). Assert `After Edit` and `5:00` are visible on the page. Clean up via `safeDelete('songs', song.id)`.

**Delete song (SONG-03):**
- `should show confirm dialog and cancel preserves song`: Use `createSong` to create a song. Right-click the song text (`click({ button: 'right' })`). Click `Delete` in context menu. Assert dialog is visible (`page.locator('dialog')`). Click cancel in dialog (`page.locator('dialog').getByRole('button', { name: 'Cancel' })`). Assert song is still visible. Clean up via `safeDelete`.
- `should delete song after confirming dialog`: Use `createSong` to create a song. Right-click, click Delete in context menu, click Delete in confirm dialog (`page.locator('dialog').getByRole('button', { name: 'Delete' })`). Assert song text is no longer visible. No cleanup needed (song is deleted).
- `should persist deletion after page reload`: Use `createSong` to create a song. Delete it via the full flow (right-click > Delete > confirm). Reload the page (`page.reload()`). Assert the song is still gone.

**Search (SONG-04):**
- `should filter songs by title when searching`: Use `createSong` twice to create `Alpha Tune` and `Beta Melody`. On `/songs`, click the search toggle (`page.getByLabel('Toggle search')`). Fill search input (`page.getByPlaceholder('Search songs...')`). Type `Alpha`. Assert `Alpha Tune` is visible, `Beta Melody` is not visible. Clear search, assert both visible again. Clean up both songs.

**Batch entry (SONG-05):**
- `should add multiple songs via sequential form submissions`: Navigate to `/songs/new`. Fill and submit song 1 (title: `Batch One`, duration: `2:30`). Assert form clears. Fill and submit song 2 (title: `Batch Two`, duration: `4:15`). Assert form clears. Navigate to `/songs`. Assert both `Batch One` and `Batch Two` are visible. Clean up: rely on worker teardown CASCADE or query and delete.

- Song form: `page.getByLabel('Title')`, `page.getByLabel('Duration')`, `page.getByRole('button', { name: 'Add Song' })`
